# Эталонное ядро среза 1 (исполняемая спецификация)

**Что это.** Минимальный серверный application service + офлайн-клиент + тесты Class A на стандартной
библиотеке Python 3.11 и SQLite. Проверяет инварианты первого вертикального среза на языконезависимых
контрактах из [`/contracts`](../../contracts).

**Чем это НЕ является.**
* Не продукт и не выбор Python базой продукта (см. `docs/blueprint/09-technology.md`, D-02).
* Не native Windows UI, не сетевой сервер, не PostgreSQL/MS SQL, не шифрованное локальное хранилище.
* Не доказательство поведения на реальной Windows/DPI/сети/многопользовательской нагрузке (это Class C).

## Запуск

```bash
cd spikes/reference-core/tests
python3 -m unittest -v
```

Зависимостей нет (только stdlib). Все БД создаются во временных каталогах и удаляются после теста.

## Что проверяется (36 тестов)

| Файл | Инварианты |
|---|---|
| `test_money.py` | Векторы `contracts/money-vectors.json`: ≤4 знаков, диапазон NUMERIC(18,4), запрет float, `null`=неизвестно ≠ `"0"`, пустая строка = ошибка |
| `test_contracts.py` | Каталог команд ↔ матрица прав согласованы; финальные эффекты — `online_required`; ГИП — только admin |
| `test_slice1_flow.py` | Заказчик → тендер → ТКП → **явное** начало РКД → проект → ГИП (admin) → РП → комплект; журнал с полномочием и версией тендера; атомарный откат при сбое; append-only журнал; секреты не попадают в журнал; деньги на границах |
| `test_authz.py` | Роль из запроса игнорируется; admin без неявных бизнес-прав; отзыв сеанса; истечение роли; проектные роли; запрет самосогласования; **отзыв + повторная выдача роли не оживляет согласование** |
| `test_offline_sync.py` | Очередь офлайн; отказ `online_required` без постановки в очередь; потерянный ответ → дедупликация по operation_id; повтор id с другими данными отклоняется; конфликт без молчаливого слияния; «отменить своё» офлайн; порядок очереди; права отозваны во время офлайна; чтение по правам; гонка двух записей; параллельный повтор одного operation_id (принятой и отклонённой операции) |

Проверка качества тестов: ручные мутации (отключение проверки версии, generation, идемпотентности,
срока роли, запрета самосогласования, условия начала РКД) — каждая роняет тесты
(протокол в `docs/blueprint/15-slice1-report.md`).

## Структура

```
vector_ref/
  money.py       деньги: Decimal, десятитысячные, JSON-строки
  contracts.py   загрузка /contracts
  schema.py      серверная схема (SQLite STRICT; журнал append-only триггерами)
  authz.py       «действие × объект × контекст» в момент эффекта
  server.py      application service: auth, authz, версии, идемпотентность, журнал — одна транзакция
  transport.py   JSON-граница + инъекция сбоев (офлайн, потерянный ответ)
  client.py      локальный кэш, очередь, синхронизация, конфликты
tests/           Class A
```
