# Безопасность ВЕКТОР

## Сообщить об уязвимости
Не создавайте публичный issue. Сообщите владельцу репозитория через приватный канал
GitHub (**Security → Report a vulnerability**) или напрямую. Укажите версию, шаги воспроизведения и возможный ущерб.

## Модель защиты (кратко)
| Угроза | Мера | Где в коде |
|---|---|---|
| Обход прав через клиента | Права проверяются на сервере в транзакции изменения; роль из запроса игнорируется | `server/authz.py`, `server/service.py` |
| Подбор пароля | Argon2id; единое сообщение; блокировка после серии ошибок; лимит попыток с адреса | `server/security.py` |
| Кража сеанса | Случайный токен, хранится хэш; срок простоя и абсолютный срок; отзыв при смене/сбросе пароля | `server/security.py` |
| Повтор/дубли операций | Устойчивый `operation_id`; повтор возвращает прежний результат; переиспользование id для другой команды — отказ | `server/service.py` |
| Тихая потеря чужих правок | Ожидаемая версия объекта; конфликт показывается пользователю, автослияния нет | `client/sync.py`, `qml/SyncPage.qml` |
| Утечка с ноутбука | Локальный кэш зашифрован; ключ в хранилище ОС; офлайн-вход ограничен сроком | `client/vault.py` |
| Перехват трафика | Только HTTPS; проверка сертификата по CA компании; HTTP — только localhost в разработке | `client/transport.py`, `server/config.py` |
| Подмена/порча резервной копии | AES-256-GCM с проверкой подлинности каждого блока; проверка после записи; восстановление только в пустую БД | `server/backup.py` |
| Секреты в файлах и журналах | Строка подключения — из переменной/файла с правами 600; маскирование в логах; пароли не принимаются из argv | `server/config.py`, `server/cli.py` |
| Скрытое изменение истории | Журнал аудита только на добавление | `server/db.py` |

## Правила для разработчиков
- Никогда не коммитить: ключи TLS, ключи резервных копий, `*.vbak`, рабочие БД, `.env`, строки подключения
  (см. `.gitignore`). Если секрет попал в историю — считать его скомпрометированным и заменить.
- Тестовые данные — только вымышленные (без реальных ИНН, имён, сумм заказчиков).
- ИИ-функции по умолчанию выключены и не имеют права согласовывать, экспортировать или менять статусы.

## Что пока НЕ проверено
Подпись инсталлятора, защита на уровне Windows (ACL, DPAPI в реальной среде), работа с реальным MS SQL,
внешний аудит/пентест. Это задачи до первой эксплуатации.
