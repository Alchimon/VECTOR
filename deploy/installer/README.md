# Установщик тестового стенда ВЕКТОР (.exe)

Один файл `VECTOR-test-stand-setup-<версия>.exe` для Windows 10/11 (x64): тестер скачивает
его, запускает двойным щелчком и отвечает на вопросы мастера — дальше всё ставится само
(сервер + клиент + демо-данные). Подробности о самом стенде — в `docs/ops/test-pc.md`.

## Что делает установщик

1. Приветствие и проверка требований (Windows 10/11 x64, Python 3.11–3.14 x64, интернет).
2. Выбор каталога стенда (по умолчанию `%USERPROFILE%\VECTOR-test`, только новый или пустой).
3. Страница паролей: пароль `admin`, пароль демо-учёток, флажки «демо-данные» и «доступ по сети».
   Пароли передаются дочернему процессу через переменные окружения (как при ручном запуске
   `setup.cmd`), никуда не записываются и не попадают в командную строку.
4. Распаковка программы во временный каталог и запуск проверенного сценария
   `deploy/test-stand/windows/setup-test-stand.ps1` (venv, `pip install -c constraints.txt`,
   тестовый сертификат, SQLite, демо-данные, ярлыки). Ход установки виден в протоколе мастера.
5. Финал: флажок «Запустить сервер и клиент сейчас». В каталоге стенда — `uninstall.exe`
   (удаляет стенд и его ярлыки).

Права администратора не нужны (кроме добровольного флажка «доступ по сети» — правило
межсетевого экрана требует администратора, как и при ручной установке).

## Сборка

Нужен NSIS 3.x (`makensis`):

- Windows: установить NSIS с https://nsis.sourceforge.io/ и выполнить
  `makensis -DPRODUCT_VERSION=<версия> -DPRODUCT_VERSION_NUM=<a.b.c.d> -DOUTFILE=dist\VECTOR-test-stand-setup-<версия>.exe -DREPO_ROOT=<корень репозитория> deploy\installer\vector-test-stand.nsi`
- Linux: `./deploy/installer/build-installer.sh` (версия берётся из `pyproject.toml`;
  путь к makensis можно задать переменной `MAKENSIS`).

Результат — `dist/VECTOR-test-stand-setup-<версия>.exe` (~5 МБ; библиотеки Python
скачиваются при установке, поэтому нужен интернет).

## Файлы

- `vector-test-stand.nsi` — сценарий установщика (NSIS, MUI2, русский).
- `check-python.ps1` — предпроверка Python 3.11–3.14 x64 до начала установки.
- `build-installer.sh` — сборка .exe из корня репозитория.

Сам стенд ставится существующим сценарием `deploy/test-stand/windows/setup-test-stand.ps1` —
не дублируйте его логику в .nsi; изменения установки вносятся туда.
