# Сторонние компоненты и их лицензии (D-82)

Программа «ВЕКТОР» использует открытые компоненты по их лицензиям. Этот файл — часть поставки
(требование лицензий Apache-2.0/BSD/MIT/LGPL: уведомление и доступность текстов лицензий).

## Клиент и сервер (Python)

| Компонент | Лицензия | Примечание |
|---|---|---|
| Python | PSF License | интерпретатор |
| Qt 6 / PySide6-Essentials | **LGPL v3** | динамическая компоновка через PySide6; пользователь может заменить библиотеки Qt/PySide6 на свои версии (пакеты Python не «заморожены»); тексты лицензий — в составе дистрибутива Qt |
| SQLAlchemy | MIT | доступ к БД (только сервер) |
| starlette + uvicorn | BSD-3-Clause | HTTP-слой сервера |
| argon2-cffi | MIT | хэширование паролей (Argon2id) |
| cryptography | Apache-2.0 / BSD | TLS, подписи (Ed25519), шифрование кэша |
| psycopg2-binary | LGPL v3 | драйвер PostgreSQL; динамическая компоновка |
| keyring | MIT | хранилище ключей ОС (только клиент) |
| httpx | BSD-3-Clause | HTTP-клиент |

## Инструменты разработки (не входят в поставку)

pytest, ruff, vulture, pgserver, python-pptx (генератор презентаций в `tools/`), PyYAML. Лицензии совместимы
(MIT/BSD/Apache); в поставляемую программу не включаются.

## Обязательства, которые мы выполняем

* LGPL (Qt, psycopg2): динамическая компоновка, уведомление здесь, текст лицензии в составе поставки,
  пользователь может заменить библиотеку (пакетная установка Python это допускает).
* Apache-2.0: файл NOTICE (этот) сохраняется; патентный грант Apache-2.0 принят.
* Тексты всех перечисленных лицензий — каталог `licenses/` в поставке (формируется при сборке релиза).

## Чего в программе НЕТ (лицензионная гигиена)

* Нет GPL-компонентов (GPL несовместим с нашей поставкой без раскрытия кода — мы их не используем;
  LibreDWG по этой причине отклонён, см. 53-ecosystem.md § 5).
* Нет кода и значков конкурентов; форматы чужих программ реализуются по открытым спецификациям.
