# Скриншоты интерфейса ВЕКТОР (основа справочного центра)

Получены **автоматически** из настоящего QML-интерфейса (не макеты): `tools/ui_harness.py` поднимает in-process сервер
на SQLite с вымышленными демо-данными, входит в клиент и снимает экраны в светлой и тёмной теме.

```bash
LD_LIBRARY_PATH=$PWD/.venv/stubgl QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
  python tools/ui_harness.py --out docs/screenshots
```

| Файл | Экран |
|---|---|
| `*-01-login` | Вход (собственные учётные записи продукта) |
| `*-02-tender-won` | Тендер «Выигран», по нему открыт проект, ТКП, история |
| `*-03-tender-tkp` | Тендер «Заявка подана»: ТКП согласовано / черновик, смена статуса |
| `*-04-project` | Проект: команда (ГИП/РП/участники), комплекты, история |
| `*-05-customer` | Карточка заказчика и его тендеры |
| `*-06-offline-pending` | Работа без связи: изменения в локальной очереди |
| `*-07-sync-conflict` | Конфликт версий: «моё изменение / сейчас на сервере», решение пользователя |
| `*-08-admin` | Администрирование учётных записей и ролей |
| `*-09-kit-tasks` | Комплект: задачи по статусам, исполнитель, срок, документ; кнопки переходов по ролям |
| `*-10-kit-documents` | Комплект: документы и неизменяемые версии файлов (размер, автор, SHA-256), загрузка и скачивание |
| `*-11-kit-calc` | Комплект: расчёт — итог черновика, пометка «итог неполный», состояние фиксации, таблица позиций |
| `*-12-kit-calc-diff` | Расчёт: сравнение черновика с зафиксированной версией, список версий (SHA-256), итог проекта по ревизии |
| `*-13-calc-editor` | Редактор позиций: проверка «на лету», сумма строки, пустая цена = «неизвестна», вставка из Excel |
| `*-14-project-totals` | «Итоги проектов» глазами бухгалтерии: только ревизии итога, без черновиков и позиций |
| `*-15-stock` | «Склад»: остатки по позициям и складам, резервы, «доступно = остаток − резерв», снимок «на момент …» |
| `*-16-stock-journal` | Журнал движений: приходы, выдачи, сторно со ссылкой на исходный документ |
| `*-17-procurement-need` | «Закупка»: потребность из зафиксированной версии, покрытие строк, «Сопоставить» у несопоставленных строк |
| `*-18-procurement-match` | Ручное сопоставление строки с номенклатурой: только позиции той же единицы, обязательная причина (A-25) |
| `*-19-stock-directory` | Склад: справочник номенклатуры и складов |
| `*-20-admin-settings` | Администрирование: настройки компании с версиями |
| `*-21-stock-transfer` | Перемещение между складами |
| `*-22-stock-transit` | Перемещение «в пути», приёмка на складе-получателе |
| `*-23-transfer-shortage-act` | Приёмка с актом недостачи |
| `*-24-transfer-loss-act` | Акт об утрате (D-31) |
| `*-25-purchase-orders` | Заказы поставщикам: список, карточка, суммы без НДС / НДС / с НДС (D-32, D-33) |
| `*-26-purchase-order-editor` | Редактор заказа: договор, «Цены в счёте», ставка НДС строки, три итога |
| `*-27-suppliers` | Поставщики: карточка с реквизитами и договорами |
| `*-28-purchase-receive` | Приём поставки по строке заказа — не больше заказанного (A-36) |
| `*-29-purchase-approval` | Заказ на согласовании: «Согласовать / Вернуть на доработку», история согласования (D-33) |
| `*-30-supplier-requisites` | Форма реквизитов поставщика с проверкой контрольных цифр (D-33) |
| `*-73-stock-adjustments` | Корректировки остатка: ждёт подписи руководителя отдела (D-77) |
| `*-74-stock-proposals` | Предложения перемещения между проектами: одно ждёт решения, одно принято — резерв переброшен (D-78) |

Ограничения: рендер программный (offscreen, Linux); вид на Windows с системным масштабированием (DPI) не проверен — Class C.
Скриншоты нужно пересоздавать при каждом изменении интерфейса (версия справки = версия UI).
