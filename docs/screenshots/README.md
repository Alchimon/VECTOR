# Скриншоты интерфейса ВЕКТОР (основа справочного центра)

Получены **автоматически** из настоящего QML-интерфейса (не макеты): `tools/ui_harness.py` поднимает in-process сервер
на SQLite с вымышленными демо-данными, входит в клиент и снимает экраны в светлой и тёмной теме.

```bash
LD_LIBRARY_PATH=$PWD/.venv/stubgl QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
  python tools/ui_harness.py --out docs/screenshots
```

| Файл | Экран |
|---|---|
| `*-01-login` | Вход (собственные учётные записи продукта) |
| `*-02-tender-won` | Тендер «Выигран», по нему открыт проект, ТКП, история |
| `*-03-tender-tkp` | Тендер «Заявка подана»: ТКП согласовано / черновик, смена статуса |
| `*-04-project` | Проект: команда (ГИП/РП/участники), комплекты, история |
| `*-05-customer` | Карточка заказчика и его тендеры |
| `*-06-offline-pending` | Работа без связи: изменения в локальной очереди |
| `*-07-sync-conflict` | Конфликт версий: «моё изменение / сейчас на сервере», решение пользователя |
| `*-08-admin` | Администрирование учётных записей и ролей |
| `*-09-kit-tasks` | Комплект: задачи по статусам, исполнитель, срок, документ; кнопки переходов по ролям |
| `*-10-kit-documents` | Комплект: документы и неизменяемые версии файлов (размер, автор, SHA-256), загрузка и скачивание |

Ограничения: рендер программный (offscreen, Linux); вид на Windows с системным масштабированием (DPI) не проверен — Class C.
Скриншоты нужно пересоздавать при каждом изменении интерфейса (версия справки = версия UI).
