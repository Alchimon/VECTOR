## Ограничения среды исполнения (влияют на доказательства)

В песочнице доступны только Python 3.11, SQLite 3.40, gcc, Node; сетевой доступ — только GitHub/PyPI/npm.
**.NET SDK, NuGet, Rust-toolchain и Qt недоступны.** Поэтому:
* spikes нативного Windows UI, .NET-сервера, DPAPI, установщика, nanoCAD, 1С **не выполнены** — описаны с критериями приёмки (`09-technology.md`);
* первый срез реализован как **эталонное ядро** (исполняемая спецификация) на stdlib Python + языконезависимые контракты в `/contracts`. Целевая реализация обязана пройти те же векторы.

## Условные обозначения статуса

* **Реализовано (эталон, Class A)** — есть код в `spikes/reference-core` и проходящие тесты; *не* продукт.
* **Спроектировано** — описано в blueprint, кода нет.
* **Заблокировано** — нужен ответ владельца / доступ / доказательство (указано, какое).
* **NO-GO** — запрещено включать до отдельного доказательства.
