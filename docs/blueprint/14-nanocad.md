# 14. nanoCAD: что такое «токен» и мастер установки DLL

> Статус: **исследование и проект**, без загрузки или установки каких-либо файлов. Официальные источники в
> этой среде недоступны (сеть ограничена GitHub/PyPI/npm), поэтому сведения о конкретных URL, версиях API
> и форматах подписи **не утверждаются** и должны быть подтверждены в spike S6 (OQ-08).

## 1. «Токен» — что под ним понимается

В прежних материалах (недоступных) смысл термина не подтверждён. Возможны три разных понятия — их
нельзя смешивать в интерфейсе:

| Понятие | Что это | Кто выдаёт | Где хранится | Используется ВЕКТОР? |
|---|---|---|---|---|
| **Токен пары «плагин ↔ ВЕКТОР»** | Короткоживущий случайный секрет, связывающий плагин в процессе CAD с запущенным desktop-клиентом того же пользователя | Desktop-клиент ВЕКТОР при запуске сеанса CAD-моста | Только в памяти; передаётся через named pipe с ACL текущего пользователя | **Да** — предлагаемый механизм |
| Лицензионный ключ/аппаратный ключ nanoCAD | Право запуска самого nanoCAD | Вендор CAD | По правилам вендора | Нет; ВЕКТОР его не читает и не хранит |
| Ключ/регистрация разработчика API у вендора | Возможное требование вендора для подписи/распространения плагинов | Вендор | У разработчика | Уточнить в S6 |

Предлагаемый токен пары (для пользователя, справка): «Это одноразовый код, по которому ВЕКТОР узнаёт,
что запрос пришёл от вашего nanoCAD на этом компьютере. Он действует только в текущем сеансе, не даёт
доступа к серверу и не сохраняется на диск». Плагин **не** получает учётные данные пользователя и не
обращается к серверу напрямую — только к локальному клиенту, который выполняет команды с правами пользователя.

## 2. Мастер загрузки/установки DLL плагина — безопасный процесс

```
1 Проверка среды   → версия nanoCAD, разрядность, путь установки, права на каталог (без повышения прав)
2 Источник         → только из списка подтверждённых источников (allowlist), утверждённого admin:
                     а) пакет, распространяемый сервером ВЕКТОР компании (загружен и проверен ИТ), или
                     б) официальный источник вендора — URL подтверждается в S6
3 Загрузка         → во временный каталог; показ: имя, версия, размер, издатель
4 Проверки         → SHA-256 = значение из подписанного манифеста сервера компании;
                     цифровая подпись Authenticode действительна, издатель = закреплённый (pinned) издатель;
                     версия плагина совместима с версией nanoCAD по матрице совместимости
5 Осознанное действие → экран «Что будет установлено, куда, как откатить»; чекбокс подтверждения выключен
6 Установка        → копирование в каталог плагинов пользователя (или в общий — только с правами администратора ПК),
                     регистрация автозагрузки способом, документированным вендором
7 Проверка         → nanoCAD загружает плагин, плагин отвечает на ping через pipe с токеном пары
8 Журнал и откат   → запись в журнал клиента (версия, hash, время, пользователь); кнопка «Удалить плагин»
```

Запрещено: устанавливать файл с непрошедшей проверкой подписи/hash; брать DLL из чатов, писем,
сторонних сайтов; молча повышать права; отключать проверки «для теста».
