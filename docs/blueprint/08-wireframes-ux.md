## 3. Маршруты по ролям (стартовый экран → частые переходы)

| Роль | Стартовый экран «Главная» показывает | Частые маршруты |
|---|---|---|
| РП | Тендеры/ТКП в работе, сроки, задачи команды, ожидающие одобрения переноса | Тендер → ТКП → «Начать РКД» → Проект → Комплекты |
| ГИП | Ожидают согласования, проекты, фиксации комплектов | Проект → Комплект → Версии → Согласовать |
| Рук. отдела | Загрузка отдела, дневные отчёты на приёмке, ТКП на согласовании | ТКП → Согласовать; Время → Принять/вернуть |
| Инженер/конструктор | Мои задачи, мои документы, замечания ко мне | Задача → Документ → Загрузить без передачи |
| Технолог | ТП на разработке/утверждении | ТП → Операции → Нормы |
| Производство | Мои операции | Наряд → Операция → Таймер/факт |
| Склад | Приходы, выдачи, подтверждения пополнения/перемещения | Подтверждения → Движение |
| Закупка | Потребности, заказы, подтверждения | Потребность → Заказ → Факт |
| Бухгалтерия | Разрешённые отчёты, сверка | Отчёты |
| Admin | Состояние сервера, пользователи, конфигурация, журналы | Пользователи → Роли; Проект → Назначить ГИП |

## 5. Дизайн-токены и темы

Семантические токены (значения подбираются в spike S1 с проверкой контраста WCAG 2.2 AA ≥ 4.5:1 для текста):
`surface/base`, `surface/raised`, `text/primary`, `text/secondary`, `accent`, `focus-ring`, `state/hover`,
`state/selected`, `state/disabled`, `status/success|warning|danger|info`, `sync/offline|pending|conflict`.
Темы: светлая и тёмная пастельная. Статус всегда дублируется **иконкой и текстом**, не только цветом.
Анимация/прозрачность — сдержанные, отключаемые (и автоматически при системной настройке «уменьшить движение»).
Плотность: «компактная / обычная». Per-monitor DPI v2; проверка 100/125/150/200 %.
Клавиатура: всё доступно с клавиатуры, видимый фокус, Ctrl+K — поиск, F1 — справка по текущему экрану.

## 6. Центр помощи

* Разделы по ролям и по сценариям (С1–С5): шаги, **зачем**, **что произойдёт**, **как проверить результат**, типичные ошибки и их коды.
* Поиск по справке; F1 открывает статью текущего экрана/шага.
* Скриншоты привязаны к версии UI (`help/{ui-version}/…`) и обновляются в том же изменении, что и экран (проверка в CI: у экрана есть статья и скриншот текущей версии).
* Матрица ролей в справке **генерируется** из `contracts/permissions*.json`, а не пишется вручную.
* Tooltips — подробные (что делает действие, что изменится, кто может), но длинный процесс — ссылкой на статью.
