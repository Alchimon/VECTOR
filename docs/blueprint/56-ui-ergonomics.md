# 56 — Эргономика интерфейса ВЕКТОР: концепт 2.0 (D-98)

> Статус: концепт, макеты в `docs/design/mockup-ribbon.png` (A) и `docs/design/mockup-tabs.png` (B).
> Реализация — отдельной оболочкой `qml2/` с переключателем в настройках; текущий интерфейс не трогаем.

## 1. Диагноз текущего интерфейса (по скриншотам docs/screenshots)

| Проблема | Откуда | Следствие |
|---|---|---|
| Мёртвая колонка списка (треть экрана) при 2–5 объектах | master-detail с фиксированной сеткой | рабочая область зажата, воздуха нет |
| Нет предпросмотра документов | документ = карточка с именем файла | чтобы понять содержимое — скачивать |
| Всё мелкое и сжатое | fsXs/fsS, отступы 6–10px | читается с трудом, «как в старой 1С» |
| Действия спрятаны в карточках/формах | нет ленты команд и контекста | «что я могу сделать» не видно |
| Нет вкладок открытых объектов | один экран = один раздел | нельзя держать спецификацию и акт рядом |
| Нет палитры команд | только мышь | клавиатурная работа медленная |

## 2. Что берём из мировых образцов

- **EPLAN Electric P8 / SOLIDWORKS PDM**: лента команд + панель предпросмотра документа (схему видно без
  открытия), дерево навигатора.
- **Microsoft Office 2024 (Fluent)**: лента с крупными кнопками и подписями, мягкие тени, щедрые отступы.
- **Linear / Figma / Notion**: воздух (базовый шаг 8px, padding карточек 16–24px), крупная типографика
  (база 15px), палитра команд Ctrl+K, hover-действия.
- **VS Code / JetBrains**: вкладки открытых объектов, статус-бар снизу, сплит-области.
- **SAP Fiori**: страница объекта с фасетами (свойства/версии/обсуждение) справа.

## 3. Два направления (выбор — за владельцем)

### Концепт A «Рабочий стол инженера» — лента + предпросмотр
- Лента сверху: разделы (Главная · Проект · Документ · Склад · Производство) → группы действий крупными
  кнопками с подписями. Контекстная: под выбранный объект подсвечиваются доступные действия (по правам).
- Три колонки: навигатор (220px, сворачиваемый) → список с воздухом → **предпросмотр (480px+)**:
  миниатюра .vsheetx/.vdocx/PDF, свойства (версия, автор, SHA-256), действия (Открыть в редакторе,
  Новая версия, PDF).
- Статус-бар снизу: связь · очередь · рабочий день — левая колонка освобождается от служебного.

### Концепт B «IDE для инженера» — вкладки + палитра команд
- Верх: хлебные крошки + палитра команд (Ctrl+K) + статус синхронизации + пользователь.
- **Вкладки открытых объектов** (как в браузере): задачи, спецификация, акт — переключение без потери
  контекста, «+» — новая вкладка.
- Центр — сам объект (таблица со строкой формул); справа — инспектор: Свойства · Версии · Обсуждение.
- Слева — узкая иконка-рейл (56px) + избранное.

### Гибрид (по умолчанию рекомендуется)
Лента из A — для разделов-списков (проекты, склад, закупка: действия «создать/назначить» — на ленте);
вкладки из B — для документов и редакторов (спецификация рядом с актом). Палитра Ctrl+K — в обоих.

## 4. Общие принципы 2.0 (независимо от направления)

1. **Воздух**: базовый шаг 8px; padding карточек 16–24px; базовый шрифт 15px (было 12–13); строки списков ≥ 44px.
2. **Предпросмотр всюду**: документы (.vsheetx/.vdocx — первые строки/лист рендером ядра; PDF — первая
   страница), задачи — описание и срок, проекты — команда и комплекты.
3. **Клавиатура первого класса**: Ctrl+K палитра, Ctrl+S/Ctrl+Enter сохранить, стрелки по спискам, Esc назад.
4. **Контекстные действия видны**: не прятать в «…» главные действия объекта; вторичные — в меню.
5. **Статус-бар снизу**: связь/очередь/рабочий день/масштаб — постоянно, без открытия разделов.
6. **Плотность настраивается**: «Уютно / Компактно» — для старых мониторов 1366×768 и для 4К.
7. Всё поверх тех же backend-API: логика (office_view, hints, лицензии, офлайн) не меняется — меняется
   только слой представления (qml2/).

## 5. План реализации (после выбора направления)

1. `qml2/Theme2.qml` — токены: шаг 8px, типографика 15/17/20, радиусы 8/12/16, тени Fluent.
2. `qml2/Shell2.qml` — каркас: лента ИЛИ вкладки + статус-бар; переключатель «Вид интерфейса» в настройках
   (QSettings, по умолчанию — классика).
3. Экран «Проекты» первым пилотом (там больше всего жалоб): предпросмотр + воздух.
4. Стенд-сцена 77 «интерфейс 2.0» — сравнительные скриншоты рядом с классикой.
5. Остальные разделы — по одному за порцию; тесты ui/ параллельно на обе оболочки.

## 6. Дизайн-система экосистемы (D-99, 2026-11-26)

Поверх каркаса 2.0 внедрён фирменный графический пак и тёмная палитра Neo-Utilitarian
(assets/vektor/manifest.json): плоские поверхности, границы 1px, акценты модулей — ХАБ (сланец),
МАРС (терракота), Юпитер (охра), Меркурий (малахит), Венера (стальной синий). Все цвета — только
из Theme.qml (страж контраста проверяет AA). Иконки — нейтральные SVG пака (currentColor, перекраска
под токен) через прежний IconProvider; цветные иконки модулей — image://icon/vmod/<id>. Логотипы:
горизонтальный — вход, эмблема — верхняя панель/сайдбар, ico — значок окна. Фирменный фон
(«VECTOR Stelt») — бренд-панель входа (всегда тёмная, в обеих темах) за вуалью ≈0,82; рабочие экраны
и пустые состояния — чистый холст (в мелких значках фон превращается в шум). Верхняя панель 2.0: эмблема + переключатель модулей с цветовой индикацией (активный = модуль
открытой вкладки: комплект → Меркурий, раздел → ХАБ; недоступные модули приглушены, с подсказкой).
