> **Стек не выбран.** Ниже — экспертная оценка (гипотеза), а не результат прототипов. Решение
> фиксируется только после spikes S1–S8 на Windows-машине разработки. Оценки 1–5 — качественные,

репозитории её **нет**, поэтому для greenfield он не является кандидатом базы (D-02).
Web frontend, browser shell, PWA, embedded WebView — исключены решением владельца.

## 2. Гипотеза (не решение)

* **Клиент:** C#/.NET (актуальная LTS на момент spike) + **WPF** как основной кандидат; WinUI 3 — запасной; Avalonia — если подтвердится потребность в кроссплатформенности (отдельное требование, сейчас не доказано).
* **Сервер:** ASP.NET Core модульный монолит; БД PostgreSQL или MS SQL (OQ-05) с NUMERIC(18,4).
* **Протокол:** выбор отдельно от языка: gRPC (контракты .proto, строгие типы, decimal как string) **или** HTTP/JSON с OpenAPI. Критерии S2: поддержка в корпоративных прокси/ACL, трассировка, генерация клиента, версионирование.
* **3D:** отдельный процесс/компонент на OCCT (C++), интеграция с клиентом через IPC — не блокирует выбор UI.
* **Rust** — кандидат для изолированных компонентов (например, верификатор переноса файлов, парсеры), если spike покажет выигрыш.
