## 5. Найденные проблемы
- Исправлено: 9 визуальных и логических дефектов UI (п. 3).
- Исправлено: эталонное ядро не запускалось после расширения каталога до v2 (`vector_ref/server.py:152`) — регрессия прошлого шага, обнаружена полным прогоном.
- Открыто: на карточке проекта знак «×» у назначений показывается по подсказке прав; итоговое решение — на сервере (отказ будет показан). Точная подсказка «может ли этот пользователь снять этого участника» — улучшение.
