## 2. Что реализовано, что только спроектировано, что заблокировано

**Реализовано (эталонное ядро, не продукт):** серверный application service с аутентификацией по
сеансу, авторизацией «действие × объект × контекст» в той же транзакции, что и эффект, идемпотентностью
по `operation_id`, оптимистичной конкуренцией, append-only журналом с полномочием (generation);
команды среза С1 (заказчик → тендер → ТКП → согласование → регистрация отправки → «Выигран» →
явное «Начать РКД» → проект → ГИП (admin) → РП → комплект); офлайн-клиент с локальным кэшем, очередью,
синхронизацией, конфликтами и восстановлением после потери ответа; денежный контракт.

**Только спроектировано:** всё, что в 01–14 помечено 📐 — в т.ч. native UI, шифрование локальной БД,
документы, расчёты, склад, производство, качество, интеграции, центр конфигурации, центр помощи.

**Заблокировано:** spikes S1–S4 (нет .NET SDK/NuGet в среде), подтверждение A-01…A-12, OQ-01…OQ-18.
