# Фирменный стиль ВЕКТОР

Решение владельца — D-28 (`docs/blueprint/12-decision-log.md`).

## Исходники (`source/`)

Файлы, присланные владельцем. Не редактируются вручную: все производные строятся из них скриптом.

| Файл | Что это |
|---|---|
| `logo-2_blueprint_business.png` | Логотип: знак «V» из чертёжной сетки, циркуля, шестерни и графиков; надпись «ВЕКТОР. Единая платформа для инженеров и бизнеса» |
| `background.jpg` | Фон: изометрическая «чертёжная» композиция в пастельных тонах |

## Производные (`src/vector/client/assets/brand/`)

Строятся командой (из корня репозитория; на Linux без GPU нужны заглушки OpenGL, см. `tools/qt_offscreen_stubs.py`):

```bash
LD_LIBRARY_PATH=.venv/stubgl QT_QPA_PLATFORM=offscreen python tools/brand_assets.py
```

| Файл | Где используется |
|---|---|
| `logo-light.png` / `logo-dark.png` | Экран входа (прозрачный фон; в тёмном варианте линии и надпись осветлены, пастель знака сохранена) |
| `mark-light.png` / `mark-dark.png` | Знак «V» 256×256: боковая панель, значок окна и панели задач |
| `bg-light.jpg` / `bg-dark.jpg` | Фон экрана входа и рабочей области (в тёмном варианте светлота инвертирована при том же оттенке) |

Чтобы сменить логотип, замените исходник под тем же именем и запустите скрипт.

## Палитра

Токены — `src/vector/client/qml/Theme.qml`. Экраны берут цвета только из токенов: тест запрещает жёстко заданные
цвета в QML и проверяет контраст по WCAG 2.1 AA (`tests/client/test_theme_contrast.py`).

| Роль | Светлая | Тёмная | Откуда |
|---|---|---|---|
| Основной (кнопки, выбор, ссылки) | `#3E6188` | `#9DBCDD` | сланцево-синий надписи и сетки логотипа |
| Текст | `#2E3846` | `#E6EBF0` | чернила надписи |
| Фон окна | `#F4F6F8` | `#12161C` | «бумага» фонового изображения |
| Информация | `#28717C` | `#8FD3CC` | мята / бирюза знака |
| Предупреждение | `#8A561A` | `#EBC08E` | персик |
| Ошибка | `#B03F37` | `#F0A096` | коралл |
| Успех | `#297649` | `#7DD0A0` | зелень знака |
| Акцент | `#6E5CA8` | `#B6A6E3` | лаванда фона |

Пороги контраста: основной и вторичный текст — не ниже 4,5:1, бледные подписи — не ниже 3:1, цвет тона на его
подложке — не ниже 4,5:1.
