Принципы, общие для всех инструкций:

* **Секреты не в файлах конфигурации и не в командной строке** — только переменные окружения, файлы с
  правами «только служба» или ввод без эха. Программа сама отказывается работать с секретом в конфигурации.
* **Fail-closed**: при сомнении в целостности (повреждённая копия, незавершённое восстановление, несовместимая
  схема) сервер не запускается, а не работает «как-нибудь».
* **Каждый шаг помечен**: ✅ — выполнен по документу в песочнице разработки (Linux, SQLite/PostgreSQL),
  🟡 — написан по документации, но на этой платформе не запускался (MS SQL, Windows Server), ⛔ — не реализован.
  Перед вводом в эксплуатацию 🟡-шаги проходит администратор компании на своей инфраструктуре (Class C).
