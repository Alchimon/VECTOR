# Юридический пакет ВЕКТОР (D-82)

Документы для честной коммерческой поставки. Это шаблоны и позиции, а не замена юристу: перед первой продажей их
подписывает/проверяет юрист владельца (вопрос OQ-53в переведён в «юрист проверяет готовое», а не «пишет с нуля»).

| Файл | Что это | Когда применяется |
|---|---|---|
| [license-agreement.md](license-agreement.md) | Шаблон лицензионного договора (ГК РФ, гл. 4) — подписка и бессрочная, с поддержкой и без, помодульно | каждая продажа |
| [privacy-note.md](privacy-note.md) | Заявление о персональных данных: при on-prem поставке мы НЕ оператор ПДн клиента | сайт, договор, справка |
| [../../NOTICE.md](../../NOTICE.md) | Сторонние компоненты и их лицензии (Qt LGPL и прочие) — лицензионная чистота | поставка, реестр, проверки |

Принципы (слова владельца: «мы работаем честно и того же хотим от других»):

1. Не блокируем данные клиента никогда — истёкшая подписка = «только чтение» (D-80).
2. Не «телефоним домой»: лицензия проверяется офлайн подписью, телеметрии нет.
3. Защищаемся договором и подписью файла лицензии, а не шпионажем за клиентом.
4. Чужие права уважаем: сторонние компоненты — по их лицензиям (NOTICE.md), чужие форматы — по открытым
   спецификациям, интерфейсы и код конкурентов не копируем.
