# Руководства ВЕКТОР

Руководства по эксплуатации: пользователю, администратору и разработчику. Пошаговые технические инструкции
(установка, резервное копирование, стенд) — в [docs/ops](../ops); проектная документация (требования, решения,
открытые вопросы) — в [docs/blueprint](../blueprint).

| Документ | Для кого | О чём |
|---|---|---|
| [user-guide.md](user-guide.md) | Сотрудники | Вход, экран, офлайн-работа и синхронизация, заказчики, тендеры и ТКП, проекты, задачи, документы, расчёты, итоги, склад, закупка, сообщения и что делать |
| [admin-guide.md](admin-guide.md) | Администратор системы | Устройство, установка, конфигурация, секреты и TLS, пользователи и роли, резервные копии, обновление, мониторинг, регламент, неисправности |
| [architecture.md](architecture.md) | Разработчик | Модули, путь команды до БД, офлайн-синхронизация, деньги, тесты, как добавить команду, инварианты |
| [reference.md](reference.md) | Все | Справочник «кто что может», команды (офлайн / только при связи), статусы и переходы. **Генерируется** из контрактов |
| [../ops/test-pc.md](../ops/test-pc.md) | Проверяющий | Тестовый стенд на одном ПК за 15 минут и сценарии проверки |

## Как поддерживается актуальность

* `reference.md` создаётся скриптом `python tools/gen_manual_ref.py` из `contracts/*.json`; тест
  `tests/core/test_manual_reference.py` падает, если справочник устарел.
* Ссылки и якоря во всей документации проверяет `python tools/check_doc_links.py` (и тест
  `tests/core/test_doc_links.py`).
* Снимки экранов снимаются из настоящего интерфейса: `python tools/ui_harness.py --out docs/screenshots`.
* Руководства описывают версию из ветки, в которой лежат. Что ещё не сделано, отмечено в конце каждого
  руководства («Ограничения текущей версии»).

Метки в документах: ✅ проверено; 🟡 написано, но не проверено на этой платформе; 📐 спроектировано, не
реализовано; ⛔ не реализовано / заблокировано.
