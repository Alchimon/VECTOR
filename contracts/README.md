# Контракты ВЕКТОР / VECTOR (языконезависимые)

Файлы в этой папке — **единый машиночитаемый источник** для:

* документации blueprint (`docs/blueprint/*`);
* эталонного ядра первого среза (`spikes/reference-core`, Python stdlib — исполняемая спецификация, не база продукта);
* будущей целевой реализации (гипотеза — C#/.NET), которая обязана пройти те же векторы.

| Файл | Что фиксирует | Статус |
|---|---|---|
| `money-vectors.json` | Разбор денежных значений: Decimal, ≤4 знаков, диапазон NUMERIC(18,4), запрет float, «неизвестно» ≠ 0 | Проверяется тестами эталонного ядра |
| `command-catalog.slice1.json` | Команды (v4: + `calc.save_draft` queued, `calc.freeze` online_required) и их офлайн-класс (`offline_full` / `queued` / `online_required`) | Проверяется тестами |
| `permissions.slice1.json` | Правила «действие × объект × контекст» среза 1 и последующих (v4: `calc.*` — расчёт комплекта, A-18) | Проверяется тестами; правила помечены как **временные предположения** (см. Decision Log) |
| `workflows.slice1.json` | Разрешённые переходы статусов тендера, ТКП, проекта | Проверяется тестами; значения — предположения |

Изменение любого файла — изменение контракта: требует записи в `docs/blueprint/12-decision-log.md`
и прогона тестов. Конфигурация администратора (раздел 8 промпта) в будущем может *сужать* эти правила
в рамках scope, но не расширять полномочия и не отключать инварианты.
